| `ins-environment-boundary-is-the-capability-boundary` | Where the environment stops is where the model stops. Agents write application code well because application work was captured — in repositories, issues and diffs — and reason poorly about MVCC and consensus because nobody ever recorded a decade of operating a cluster in a form a model could train on. So the unit of training data for autonomous engineering cannot be the diff; it has to be **the company**: the tickets and postmortems that explain why the last migration went wrong, the customer conversations that explain what "down" costs, the stale documentation the agent must notice is stale, the deployment system that conflicts with itself, and the live traffic that makes every choice carry a blast radius. As long as the environment ends at the repository boundary, so does the model — and every benchmark on the current frontier ends there | `HighlightsPattern → pat-verification-gap` **[registry]** | `ReliesOnElement → el-company-in-a-sandbox`, `el-infra-capability-gap`, `el-agentic-environment` **[registry]** |
| `ins-fidelity-has-a-hardware-floor` | The standardized environment format has a physical ceiling, and it is reached sooner than the field assumes. A single containerized node can fake a surprising amount — multiple cluster members, flapping nodes, lagging learners, even live traffic — and deterministic simulation can fake network partitions, but neither can fake **provisioning**: the moment the task involves creating a host, a VPC, a security group or a customer-facing API with throttling and audit logging, the simulation stops being a simulation of the thing and starts being a different thing. That pushes environments toward provisioning real cloud resources, which imports real costs into training: an AWS-Lambda-scale stack takes **hours** to stand up against a rollout budget measured in minutes, and the bill is real. And the honest close is that **it does not even close the gap** — with real infrastructure you still have no live customer traffic and none of the problems that only appear at scale. Fidelity is not a switch you flip; it is a budget you spend, and the last increment is unpurchasable | — (no pattern edge; the industry-level claim is carried by the two pattern-less signals awaiting `pat-environments-economy`) | `ReliesOnElement → el-multi-node-sandbox`, `el-deterministic-simulation` **[registry]**, `el-harbor` **[registry]** |
