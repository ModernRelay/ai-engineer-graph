| `el-audit-task` | The audit task | concept | security | Replaces the standard RL prompt "find and exploit *the* vulnerability" with "find **all** vulnerabilities". Uniquify submissions deterministically by stack backtrace (the technique Windows/macOS crash reporting already uses) so two distinct bugs cannot be counted once. When the model proves a bug you did not know about, add it to the known set and renormalize.
